# Study Focus Extension

This  is my final cs50 project, I decided to implement browser extension designed to help users improve productivity by blocking distracting social media sites during timed study sessions.

## Features

* Blocks social media platforms (e.g., Facebook, Instagram).
* Allows customizable timer settings for study periods.
* Simple and intuitive interface.

## How to Use

1. Clone or download the repository.
2. Load the extension in your browser (via developer mode).
3. Start a study session by setting the timer and the extension will automatically block the selected social media sites during that time.
